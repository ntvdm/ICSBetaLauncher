# ICSBetaLauncher
Port of the Android 4.0 Launcher seen in pre-release builds like IRK40C

- Supports up to Android 16 
- custom Icon support (tutorial below)
- Widgets can be bind without adb (you get a popup instead!)



How to use custom icons:
You need https://f-droid.org/packages/com.kaanelloed.iconeration/
Edit your Icons using that
then install the launcher AFTER you installed the icon pack
